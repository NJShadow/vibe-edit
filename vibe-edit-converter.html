VIBE EDIT — Project Converter

Converts older .cutroom projects to the new .vibe format.

Drop .cutroom files here or click to choose — you can select as many as you like
Nothing leaves your computer. Conversion happens entirely in this page — no upload, no server.

Your media is untouched. A project file only stores edits and the paths to your footage, so converting changes the file's label, not your video or audio.

The original is kept. Converting writes a new .vibe file alongside it; your .cutroom file is not modified or deleted.

You may not need this. Vibe Edit opens .cutroom projects directly — this tool is just for tidying an older library into one consistent format.
